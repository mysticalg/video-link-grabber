Install the helper

Close active download queues before installing or updating.

Windows

Download and run Setup.exe. Keep “Install missing tools” selected to obtain Python, Node.js and FFmpeg through Windows Package Manager. Compatible tools are reused. Windows may request administrator approval for a dependency.

The installer is unsigned and may show an unknown-publisher warning. Do not disable Windows security protections.

macOS

Choose Apple Silicon for an M-series Mac, or Intel for an Intel Mac. Find this under Apple menu → About This Mac. Open the PKG installer and follow the macOS installer steps. Administrator approval is required. Python, Node.js and the media tools are included privately.

These first Mac packages are unsigned and not notarized. macOS or your organization may block installation; no verified Apple developer identity is claimed. Do not disable Gatekeeper or other security protections.

Linux

Open the DEB or RPM in your distribution's package installer and approve installation. The helper's runtime and media tools are included; your package manager resolves standard system libraries.

Use a normally installed Google Chrome or Chromium browser. Snap and Flatpak browser isolation is not supported. If your desktop does not open package files, use sudo apt install ./video-link-grabber-local-1.5.0-linux-x64.deb or sudo dnf install ./video-link-grabber-local-1.5.0-linux-x64.rpm from the download folder.

Finish in Chrome

  1. Open chrome://extensions and enable Developer mode.
  2. Choose Load unpacked and select the extension folder for your OS:
    Windows
    %LOCALAPPDATA%\VideoLinkGrabberLocal\extension
    macOS
    /Library/Application Support/VideoLinkGrabberLocal/extensionIn the Mac folder picker, press Command + Shift + G to paste the path.
    Linux
    /opt/video-link-grabber-local/extension
    If an older Local edition is loaded from another folder, remove that Local entry before loading this one. For an update in the same folder, click Reload.
  3. Open a YouTube video and click Video Link Grabber Local. Check for YouTube helper ready, then choose Download.

Keep the queue tab open until it finishes. Videos go to Downloads/Video Link Grabber; the queue shows the exact saved path. They do not appear in Chrome's download history.

Setup help

I already have the Chrome Web Store extension

The helper alone does not add YouTube support to the Store edition. Install the separate Local edition and follow the Chrome step above. Websites and these installers do not silently add unpacked extensions to Chrome.

Downloads fail or the helper is missing

Restart Chrome after installation and check that the Local edition is loaded from the correct folder. On Windows, use Repair helper in the Start menu. On macOS or Linux, rerun the package installer. For a temporary HTTP 403, use Retry unfinished. If failures continue, the video may be unavailable or the downloader may need an update. Private, login-required, membership-only, live and DRM-protected videos are not supported.

What is installed, and how do I remove it?

Windows installs into your account's LocalAppData/VideoLinkGrabberLocal folder; remove it through Settings → Apps. Linux installs into /opt/video-link-grabber-local; remove the video-link-grabber-local package using your package manager. Mac files live in /Library/Application Support/VideoLinkGrabberLocal, with Chrome host registration under /Library/Google/Chrome/NativeMessagingHosts and Chromium registration under /Library/Application Support/Chromium/NativeMessagingHosts.

Remove the Local extension in Chrome too. Your saved videos stay in Downloads. Mac/Linux store a small per-user configuration in ~/Library/Application Support/VideoLinkGrabberLocal or ~/.config/VideoLinkGrabberLocal respectively.

Privacy, limits and source code

The helper receives selected video IDs and contacts YouTube and its media hosts. It does not import browser cookies, collect account tokens or send telemetry. Downloads are limited to 1080p, two hours and 2 GB; jobs time out after 30 minutes. Only save content you have permission to download.
