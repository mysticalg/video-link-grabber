Version 1.4.2 · Windows 10/11, x64 · Internet required
This is the separate Local edition. The Chrome Web Store edition does not use this YouTube helper.

Install once. Then download from Chrome.

  1. Download and run Setup.exe. Close any active download queues first. The wizard installs into your Windows account.
  2. Let the wizard prepare the helper. Keep “Install missing tools” selected to obtain Python, Node.js and FFmpeg through Windows Package Manager. Compatible tools already on your PC are reused. Windows may ask you to approve a dependency installer.
  3. Finish the Chrome step below. Chrome requires you to load the Local extension yourself. If you already have this edition in the installed folder, simply reload it.

The installer is unsigned, so Windows may show an unknown-publisher warning. No verified publisher is claimed. Do not disable Windows security protections. View release details, source and SHA-256 checksums.

Finish in Chrome

  1. Open chrome://extensions and enable Developer mode.
  2. Choose Load unpacked, then paste this into the folder picker:%LOCALAPPDATA%\VideoLinkGrabberLocal\extensionIf you loaded an older Local edition from another folder, remove that Local entry before loading this one, or update its existing files using the ZIP.
  3. Open a YouTube video and click Video Link Grabber Local. Check for v1.4.2 and YouTube helper ready, then choose Download.

Keep the queue tab open until it finishes. Videos go to Downloads\Video Link Grabber; the queue shows the exact saved path. They do not appear in Chrome's download history.

Setup help

I already have the extension

If it is named Video Link Grabber Local, run the installer once and reload that Local entry. If it is the Chrome Web Store edition, the helper alone will not add YouTube downloads; follow the Local installation steps above. Chrome does not allow websites or installers to silently add this unpacked extension.

A required tool could not be installed

Setup uses WinGet / App Installer. If unavailable, install it or obtain Python 3.10+, Node.js 22+ and FFmpeg with FFprobe manually. Rerun Setup or use Repair helper in the Start menu. The helper also downloads Python packages from PyPI.

Downloads fail or the helper is missing

Run Repair helper from the Start menu. For a temporary HTTP 403, use Retry unfinished. If the error continues, the video may be unavailable or the downloader may need an update. Private, login-required, membership-only, live and DRM-protected videos are not supported.

What is installed, and how do I remove it?

The helper, private Python packages and extension files live in your account's LocalAppData\VideoLinkGrabberLocal folder. Only the Local extension can connect. Use Windows Settings → Apps → Video Link Grabber Local → Uninstall, then remove the Local extension in Chrome. Saved videos and separately installed Python, Node.js and FFmpeg are kept.

Privacy, limits and source code

The helper receives selected video IDs and contacts YouTube and its media hosts. It does not import browser cookies, collect account tokens or send telemetry. Downloads are limited to 1080p, two hours and 2 GB; jobs time out after 30 minutes. Only save content you have permission to download.
